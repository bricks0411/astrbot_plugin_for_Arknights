# AstrBot 明日方舟综合查询插件

为 AstrBot 提供明日方舟官服账号登录、抽卡记录统计、账号资料查询和干员百科查询。

## 安装

将本仓库安装到 AstrBot 的 `data/plugins` 目录，或通过 AstrBot 插件管理界面安装。

安装后请重启 AstrBot。插件使用图片展示统计结果和资料卡片，请确保 AstrBot 的图片渲染服务可用。

目前只支持明日方舟官服，B 服暂不支持。

## 使用前准备

登录和账号资料同步只能在私聊中进行。首次使用时，请先完成官服登录；登录成功后，凭证会保存在本机，之后重启 AstrBot 通常不需要重新登录。

所有命令都需要使用 AstrBot 当前配置的命令前缀，下面以 `/` 为例。

## 登录官服

1. 私聊机器人发送手机号，获取验证码：

   ```text
   /方舟官服登录 <手机号码>
   ```

2. 在验证码有效期内提交验证码：

   ```text
   /官服验证码 <验证码>
   ```

登录成功后即可使用抽卡和账号资料相关功能。

## 抽卡记录

先同步服务器上的记录：

```text
/官服抽卡记录更新
```

再查看统计结果：

```text
/官服抽卡记录查询
```

统计内容包括总抽数、当前垫抽、六星记录和卡池信息。服务器只能提供有限时间范围内的记录，建议定期执行“抽卡记录更新”，以免遗漏新记录。

## 账号资料

登录后，先更新账号资料：

```text
/官服角色信息更新
```

查看账号总览：

```text
/官服角色信息查询
```

查看干员练度总览：

```text
/官服干员列表查询
```

账号资料较多，生成干员列表时可能需要等待一段时间；如果渲染失败，请稍后重试。

## 干员百科

查询指定干员：

```text
/干员百科 <干员名称>
```

结果通常包含干员头像、立绘、基础属性、技能和模组信息。首次查询或资料更新时需要访问 PRTS Wiki；如果图片生成失败，插件会尝试发送文字结果。

## 其他命令

`/方舟B服登录` 当前会提示暂不支持 B 服登录。

## 注意事项

- 手机号登录和验证码提交仅限私聊，避免在群聊中发送账号信息。
- 账号凭证、抽卡记录和账号资料会保存在 AstrBot 主机本地，请妥善保护 AstrBot 数据目录。
- 本插件依赖明日方舟官方服务和 PRTS Wiki；相关服务异常或页面调整时，部分功能可能暂时不可用。
